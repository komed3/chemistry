# Chemistry Tools

**Chemistry Tools** is a central documentation and interactive playground platform for my chemistry-related TypeScript libraries.

The project brings together the documentation and browser-based playgrounds for [ChemParse](https://github.com/komed3/chemparse) and [ChemBalance](https://github.com/komed3/chembalance). It provides an overview of their features, installation instructions, API references, usage examples, and supported syntax.

Both libraries can be used directly in the browser without installing anything. The interactive playgrounds allow you to experiment with chemical formulas, compare expressions, inspect parsed results, and balance chemical reaction equations.
